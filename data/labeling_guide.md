# 장소 추천 PoC — 라벨링 기준표 (v0.2)

> v0.2: 관광 명소를 "유명한가"가 아니라 "볼거리가 분명하고 밖에서 즐길 수 있는가"로 채점 (인기 편향 방지)

쿼리 1건 = 페르소나(취향 1~3개, 주간/야간) + 출발·도착 + 목표거리 + 후보 장소 최대 20개.
후보마다 **러닝 코스에 넣었을 때 이 사용자가 얼마나 만족할지**를 0~3점으로 매긴다.

## 1. 기본 점수 (취향별)

| 점수 | 야경 | 관광 명소 | 자연·공원 |
|---|---|---|---|
| 3 | 야간 조명·경관이 핵심 (조명 다리, 미디어파사드, 분수, 야경 전망) | 볼거리가 분명하고 **밖에서** 즐길 수 있는 곳 (고궁, 성곽길, 벽화·한옥마을, 역사공원, 특징적인 건축물) | 큰 공원·한강공원·숲길·산책로 (러닝에 적합) |
| 2 | 밤 분위기가 좋은 곳 (광장, 한옥·먹자 거리, 전망 시설) | 볼거리는 있지만 규모가 작거나 일부만 밖에서 즐길 수 있음 (작은 유적·성문, 골목·먹자 거리, 대형 박물관) | 근린공원·광장·정원·식물원(온실 포함) |
| 1 | 밤에 외관 정도는 볼 수 있음 | 실내 위주 (작은 갤러리·사찰·기념물·체험관) | 작은 녹지, 나무·바위 같은 단일 자연물 |
| 0 | 무관 | 무관 | 무관 |

- **상점·체험 업체·식당·도서관·문화원·공연장 내부**는 취향과 상관없이 0 (러닝 중 들를 곳이 아님)
- 판단 근거는 **장소명 + 개요**. 카테고리 값은 참고만 한다 (예: 남산케이블카는 '기타'지만 야경 2)
- **유명도는 근거로 쓰지 않는다.** 개요의 "대표적인", "유명한", "세계유산" 같은 표현이 아니라 러너가 지나가며 보고 즐길 거리가 있는지로 판단한다

## 2. 조정

1. **시간대**
   - 주간 + 야경 취향 → 야경 기준 점수 −1 (낮에는 조명 효과 없음)
   - 야간 + 밤에 닫거나 어두운 곳 (고궁 내부, 박물관·미술관, 산·숲길, 온실) → −1
   - **(v0.3) 야간 + 야경 취향 + 서울시 야경명소(`night_spot`) → 야경 점수 +1** (밤에 야경명소 우대. 예: 경복궁 야경·밤 1 → 2)
2. **거리**: `detour_km > 목표거리 × 0.5` → −1 (코스에서 너무 멀리 돌아가야 함)
3. 최종 점수는 0~3으로 자른다

## 3. 취향을 여러 개 고른 경우

취향별로 1~2단계 점수를 각각 매긴 뒤 **최댓값**을 쓴다 (모델의 KURE 유사도 max와 같은 방식).

## 4. 라벨링 방식

1~3단계 규칙은 쿼리마다 같으므로, **장소 단위로 한 번만** 채점하고 쿼리 라벨은 규칙으로 계산한다.
- 장소별 채점 (`place_scores.jsonl`): `night`·`sight`·`nature` 기본 점수(0~3), `closed_night`(밤에 닫거나 어두움 0/1)
- 쿼리 라벨 계산 (`compute_labels.py`): 취향별로 기본 점수 → 주간 야경 −1 → 야간 `closed_night` −1 → 야간 야경명소 +1 → 최댓값 → 거리 −1 → 0~3

## 5. 평가 지표 기준

- HitRate@5: 상위 5개 안에 **2점 이상** 장소가 있는가 (3점은 거리 감점 때문에 드물어서 2점 이상으로 완화)
